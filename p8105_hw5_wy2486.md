## Problem 1

### Probability that at least two people share a birthday

In this problem, I use simulation to estimate the probability that at
least two people share a birthday in a group.

``` r
birthday_repeated = function(n_people) {
  birthdays = sample(1:365, size = n_people, replace = TRUE)
  repeated_birthday = length(unique(birthdays)) < n_people
  return(repeated_birthday)
}

birthday_results =
  expand_grid(
    n_people = 2:50,
    iter = 1:10000
  ) |>
  mutate(
    repeated = map_lgl(n_people, birthday_repeated)
  )

birthday_summary =
  birthday_results |>
  group_by(n_people) |>
  summarize(
    prob_repeat = mean(repeated)
  )

birthday_repeated(5)
```

## Problem 3

### Simulation to Explore Power in a One-Sample T-Test

In this problem, I use simulation to investigate how the true mean
affects statistical power in a one-sample t-test. The sample size is
fixed at 30, the standard deviation is fixed at 5, and 5000 datasets are
generated for each true mean from 0 to 6.

``` r
sim_t_test = function(mu, n = 30, sigma = 5) {

  sim_data =
    tibble(
      x = rnorm(n, mean = mu, sd = sigma)
    )

  test_result =
    t.test(sim_data$x, mu = 0) |>
    broom::tidy()

  return(
    tibble(
      mu_hat = test_result$estimate,
      p_value = test_result$p.value
    )
  )
}

sim_results_df =
  expand_grid(
    true_mu = 0:6,
    iter = 1:5000
  ) |>
  mutate(
    estimate_df = map(true_mu, sim_t_test)
  ) |>
  unnest(estimate_df) |>
  mutate(
    reject_null = p_value < 0.05
  )
```

very close to the true mean. However, when looking only at samples with
significant results, the average estimated mean tends to be higher than
the true mean, especially when the true mean is small and positive. As

becomes smaller. This suggests that focusing only on significant results
can lead to overestimating the true effect.
